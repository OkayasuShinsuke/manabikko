# まなびっこ / Advanced Lab

学習用のWebアプリを2本まとめたリポジトリです。どちらも1ファイルのHTML+JS+CSSで動く、
サーバーレスに近い作りになっています（`server.js` はセーブの複数端末対応と、任意の
VOICEVOX連携だけを担当します）。

| アプリ | 対象 | 場所 |
|---|---|---|
| **まなびっこ** | 幼児〜小学3年生 | `public/kids/index.html` |
| **Advanced Lab** | 高校生〜大学院生（電磁気学）・大学受験生（東大数学） | `public/advanced/index.html` |

## セットアップ

```bash
npm install
npm start
```

起動後、`http://localhost:3000/kids/`（まなびっこ）または
`http://localhost:3000/advanced/`（Advanced Lab）でアクセスできます。

### スマホから開く（同じWi-Fi内）

本アプリは `0.0.0.0` で待ち受けるため、PCのローカルIPでアクセスできます。

1. PCのローカルIPを確認（macOS/Linux: `ip a`、Windows: `ipconfig`）
2. スマホから `http://<PCのローカルIP>:3000/kids/` を開く

## まなびっこ（幼児〜小3向け学習ゲーム）

メンダコのキャラクター「メンちゃん」と一緒に遊ぶ、タップ中心の学習ゲームです。

| ゲーム | 内容 |
|---|---|
| かず | じゅうのわくに並んだものを数える |
| たしざん・ひきざん | くり上がり・くり下がりを含む計算（レベルで難易度変化） |
| かけざん | 九九（Lv4以降） |
| わりざん | あまりのある割り算（Lv5） |
| とけい | アナログ時計の読み方（Lv5） |
| ひらがな・どっち？・いろ | 文字・数量比較・色の学習 |

- レベルは5段階（やさしい〜5 / むずかしい〜10 / 小1〜20 / 小2 / 小3）
- 正解・れんぞく正解・パーフェクトで演出が変わるパチンコ風の効果音（Web Audio API合成）
- コインを集めて「きせかえ」「ごはん」でメンダコとの「なかよし度」を上げられる
- 問題文は音声で読み上げ（後述のVOICEVOX、または標準のWeb Speech API）
- 「ひきつぎコード」でセーブデータを別端末に引き継げる（`npm start` の実サーバー経由のみ。
  claude.aiのArtifactプレビューでは動きません）

### より自然な読み上げにする（VOICEVOX連携・任意）

無料の音声合成エンジン **[VOICEVOX](https://voicevox.hiroshiba.jp/)** をPCで起動していると、
自動的にそちらの声（デフォルトは「ずんだもん」）で読み上げます。起動していなければ、
自動でブラウザのWeb Speech APIにフォールバックするので、無くても問題なく遊べます。

```bash
VOICEVOX_SPEAKER=3 npm start   # 話者IDを変えたい場合（GET /speakersで確認）
```

VOICEVOXはキャラクターごとのクレジット表記が必要です。話者を変えた場合は、
ホーム画面の「おんちの かたへ」欄のクレジット表記も合わせて変更してください。

## Advanced Lab（電磁気学・東大数学）

高校〜大学院レベルの電磁気学（全10トピック、パラメータ自動生成）と、東大入試レベルの
数学（厳選問題バンク）を、途中式を省略しない解説つきで学べるアプリです。

- 電磁気学は毎回パラメータをランダム生成し、出題と採点を同じ式から計算（ズレが起きない設計）
- 全ての問題に「公式の根拠」「別解（可能なもの）」「SVGの図解」「用語の一言定義」を用意
- 数式表示は [KaTeX](https://katex.org/)（CDN読み込み。claude.aiのArtifactプレビューでは
  CSPの制限で数式が生のLaTeXテキストのまま表示されます。`npm start` の実サーバーなら
  正しく表示されます）
- 自己採点を記録し、間隔反復での復習に使えるデータ形にしてある
- ストリーク・XP表示、ライト/ダーク両テーマ対応
